# Portfólio profissional — Gabriel Alexandre de Matos

Site estático em HTML, CSS e JavaScript, preparado para publicação gratuita no GitHub Pages.

## Publicar pelo iPhone

1. Entre em https://github.com e crie uma conta ou faça login.
2. Crie um repositório novo. Para um endereço do tipo `https://SEU-USUARIO.github.io`, o nome do repositório precisa ser exatamente `SEU-USUARIO.github.io`, substituindo pelo seu nome de usuário do GitHub.
3. Escolha **Public** e crie o repositório.
4. Abra o repositório e use **Add file** → **Upload files**.
5. Envie o arquivo `index.html` deste pacote e confirme em **Commit changes**.
6. Abra **Settings** → **Pages**.
7. Em **Build and deployment**, selecione **Deploy from a branch**; escolha a branch `main` e a pasta `/(root)`, depois salve.
8. Aguarde a publicação. O GitHub mostrará o endereço do site na área **Pages**. Pode levar alguns minutos.

## Antes de publicar

- Revise todas as informações pessoais e profissionais.
- Este site exibe seu e-mail e número de telefone publicamente. Publique-os apenas se estiver confortável em deixá-los visíveis para qualquer pessoa na internet.
- O conteúdo mantém os dados fornecidos e não adiciona empregadores, diplomas ou habilidades não informados.

## Atualizar o site

Edite o arquivo `index.html` no repositório e salve as mudanças com **Commit changes**. O GitHub Pages publicará a atualização automaticamente após o processamento.
